## AirBnb_NYC_2019

Hey there! 👋

This project is an exploratory dive into the New York City Airbnb listings dataset, titanic datasets and scholarship datasets. My goal was to clean the data, understand its structure, and uncover insights into pricing, neighborhood trends, and host behaviors across the city, how to encourage scholarships.

💡 Why I Did This:

1. To sharpen my skills in real-world data cleaning and distribution analysis
2. To explore patterns in Airbnb listings across NYC’s boroughs
3. To practice outlier handling and understand guest-host dynamics
4. Scholarships and students relations

🛠️ What I Did:

1. Performed data cleaning: handled missing values using interpolation, removed duplicates, and fixed inconsistent entries
2. Analyzed data distribution (normal vs skewed) for key variables like price, availability, and reviews
3. Applied Z-score method for outlier detection and used capping to handle extreme values
4. Conducted EDA to understand patterns in listing types, price ranges, availability, and review counts
5. Explored neighborhood group behavior, identifying high-traffic and high-price areas

📌 Key Takeaways:

1. Prices were highly skewed, with a few extreme listings impacting averages
2. Manhattan and Brooklyn had the most listings, but with very different pricing trends
3. Z-score and capping helped bring more stability to the data for better visualization and understanding
4. Some hosts listed hundreds of properties, showing the presence of commercial rentals in the platform

🧰 Tech Stack:

1. Python (Pandas, NumPy, SciPy, Matplotlib, Seaborn)
2. Jupyter Notebook for step-by-step exploration

📚 What I Learned:

1. How to detect and handle skewed distributions and outliers
2. The importance of contextual analysis in real estate/booking data
3. Enhanced my data storytelling through visualization and interpretation
